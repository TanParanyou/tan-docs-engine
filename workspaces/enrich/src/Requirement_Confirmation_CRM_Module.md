## ส่วนที่ 2: นิยามคำศัพท์ที่ใช้ร่วมกัน (Glossary & Definitions)
* **CRM (Customer Relationship Management)**: ระบบบริหารจัดการความสัมพันธ์ลูกค้าสำหรับดูประวัติการรับบริการ สิทธิ์คงเหลือ และจัดการ Consent
* **Service Rule / Reminder**: เงื่อนไขการสร้างการแจ้งเตือนอัตโนมัติเพื่อให้ลูกค้ากลับมาใช้บริการตามช่วงเวลาที่กำหนด
* **Before / After Photos**: รูปภาพเปรียบเทียบผลลัพธ์ก่อนและหลังการรับบริการ ผูกกับข้อมูลลูกค้าและ Order
* **Consent (PDPA)**: การยินยอมของลูกค้าในการจัดเก็บ ใช้หรือรับข้อมูลข่าวสาร/ภาพถ่าย ตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล
* **Point / Course / Credit / Voucher**: สิทธิประโยชน์สมาชิก โดย Point คือแต้มสะสม, Course คือจำนวนครั้งบริการ, Credit คือยอดเงินสะสมใน Wallet , Voucher คือคูปองส่วนลด

## ส่วนที่ 4: รายละเอียด Requirement Confirmation แยกข้อ (Detailed Requirements)

### REQ-MBR-001 — การสมัครสมาชิกและจัดการโปรไฟล์ผ่าน LINE OA (Member Registration & Profile)

1. Requirement จากการประชุม: ลูกค้าสามารถสมัครสมาชิก บันทึกข้อมูลส่วนตัว และให้ Consent PDPA ผ่าน LINE Rich Menu เพื่อเริ่มต้นใช้งานระบบสมาชิก

2. พฤติกรรมที่คาดหวัง (Expected Behavior):
* ลูกค้าเข้าใช้งานครั้งแรกผ่าน LINE OA Rich Menu แล้วเลือกระบบสมาชิก
* กรอกข้อมูลสมัคร: ชื่อ-นามสกุล(บังคับ), ชื่อเล่น, เบอร์โทรศัพท์(บังคับ), วันเกิด(บังคับ) และอีเมล
* แสดงข้อความยินยอม PDPA (Consent) ให้ลูกค้ายินยอมก่อนบันทึกข้อมูล
* สมาชิกเข้าดูและแก้ไขข้อมูลโปรไฟล์ของตนเองผ่าน LINE OA ได้ตลอดเวลา ยกเว้นเบอร์โทรศัพท์และวันเกิด

3. ตัวอย่างการยอมรับ (Acceptance Criteria): ลูกค้าแอด LINE OA -> กดสมัครสมาชิก -> กรอกชื่อ เบอร์ วันเกิด และติ๊ก PDPA Consent -> ระบบสร้างโปรไฟล์สมาชิกพร้อมให้สิทธิ์ต้อนรับ/แต้มเริ่มต้นทันที

4. ประเด็นที่ต้องยืนยันเพิ่มเติม / เงื่อนไขเลือก:
* ช่องทางหลักในการส่งแจ้งเตือน: [ X ] LINE OA

### REQ-CRM-002 — หน้าจอ CRM บนโทรศัพท์มือถือ (Mobile CRM Screen)

1. Requirement จากการประชุม: แสดงหน้าจอศูนย์รวมสิทธิ์สมาชิกแบบ Responsive Web บนมือถือที่เข้าถึงได้ผ่าน LINE OA ให้ความรู้สึกเนียนเหมือนใช้งานแอปพลิเคชัน

2. พฤติกรรมที่คาดหวัง (Expected Behavior):
* แสดงยอด Point คงเหลือ, ระดับสมาชิก (Tier: เช่น Silver, Gold) และยอด Wallet/Credit คงเหลือ
* แสดงรายการ คอร์สบริการ (Course) คงเหลือ และจำนวนครั้งที่คงเหลือ (เช่น Fusio-Dose คงเหลือ 3/5 ครั้ง)
* แสดงประวัติการรับบริการ (Service History) และประวัติการใช้สิทธิ์ Point/Wallet/Course
* แสดงรายละเอียดแพ็กเกจที่ซื้อ สิทธิพิเศษตาม Tier และวันหมดอายุของแต่ละสิทธิ์
* แสดงข้อมูลสิทธิพิเศษและสามารถกดแลกจากแต้มได้

3. ตัวอย่างการยอมรับ (Acceptance Criteria): สมาชิกกดเมนู 'ข้อมูลสมาชิก' ใน LINE -> เปิดหน้า Web Portal แสดงคะแนน 133 แต้ม, ยอด Wallet 10,000 บาท, คอร์สสระผมคงเหลือ 3 ครั้ง พร้อมปุ่มดูประวัติย้อนหลังได้ชัดเจน, แสดงข้อมูลสิทธิพิเศษ

### REQ-MBR-003 — ระบบสะสมแต้ม แลก Point และสิทธิประโยชน์สมาชิก (Member Points & Privileges)

1. Requirement จากการประชุม: ระบบสะสม Point จากการซื้อสินค้า/บริการ, การแบ่งระดับสมาชิก (Tier) และการแลก Point เป็นส่วนลดหรือรางวัลผ่าน LINE OA

2. พฤติกรรมที่คาดหวัง (Expected Behavior):
* สะสม Point อัตโนมัติเมื่อชำระเงินค่าสินค้า/บริการสำเร็จ ตามอัตราที่กำหนด
* กำหนดสิทธิประโยชน์และอัตราสะสมแต้มที่แตกต่างกันตามระดับสมาชิก (Tier: Silver / Gold)
* สมาชิกเลือกกดแลก Point เป็นส่วนลด, สินค้า หรือบริการผ่านหน้า Member Portal ได้เอง
* แสดงประวัติการได้รับ Point, การใช้ Point แลกรางวัล

3. ตัวอย่างการยอมรับ (Acceptance Criteria): สมาชิกมี 500 Point กดแลกส่วนลด 50 บาทผ่าน LINE Portal -> ระบบตัด 500 Point และสร้าง Discount Code ให้หน้าร้านนำไปสแกนตัดส่วนลดใน Order

### REQ-MBR-004 — การใช้ Wallet / Course / Package และการยืนยันด้วย OTP

1. Requirement จากการประชุม: เมื่อนำ Wallet หรือ Course ของสมาชิกมาใช้ชำระเงินหน้าร้าน ระบบต้องส่ง OTP ยืนยันไปยังสมาชิกก่อนตัดสิทธิ์จริงเสมอ

2. พฤติกรรมที่คาดหวัง (Expected Behavior):
   1. เมื่อพนักงานเลือกตัด Wallet หรือ Course ใน Order ระบบส่ง OTP ไปยัง LINE OA ของสมาชิก
   2. สมาชิกแจ้งรหัส OTP แก่พนักงานเพื่อกรอกยืนยันใน POS หน้าร้าน
   3. เมื่อยืนยัน OTP สำเร็จ และทำการชำระเงิน ระบบตัดยอด Wallet/Course และส่งข้อความแจ้งเตือนผลการตัดยอดเข้า LINE OA สมาชิกทันที
   4. รองรับกรณีครอบครัว (เช่น แม่-ลูก) ใช้ Wallet ร่วมกัน โดยขอ OTP ครั้งเดียวเพื่อตัดหลายบิลได้

3. ตัวอย่างการยอมรับ (Acceptance Criteria): พนักงานเลือกลด Wallet 2,000 บาท -> ระบบส่ง OTP เข้า LINE สมาชิก -> กรอก OTP สำเร็จ ทำการชำระเงิน ยอด Wallet ตัดเหลือ 8,000 บาท และมีข้อความ LINE แจ้งเตือนยอดคงเหลือทันที

### REQ-MBR-005 — ระบบแจ้งเตือนอัตโนมัติสำหรับสมาชิก (Member Auto Reminders via LINE OA)

1. Requirement จากการประชุม: ระบบส่งข้อความแจ้งเตือนอัตโนมัติไปยัง LINE OA ของสมาชิก เช่น โปรวันเกิด, เตือนกลับมาทำบริการบำรุง และเตือนนัดหมาย

2. พฤติกรรมที่คาดหวัง (Expected Behavior):
* แจ้งเตือนส่วนลด/สิทธิประโยชน์เดือนเกิดแก่มองสมาชิกอัตโนมัติเมื่อถึงเดือนเกิด
* แจ้งเตือนเตือนสมาชิกกลับมาทำบริการ B หลังทำบริการ A ตามระยะเวลาที่ตั้งไว้ใน Service Rule
* ตรวจสอบ Consent และช่องทางที่สมาชิกรวมถึงยกเลิกการเตือนอัตโนมัติหากสมาชิกล่วงหน้าเข้ามาทำบริการก่อน
* แจ้งเตือนเตือนนัดหมายล่วงหน้าก่อนถึงเวลานัดรับบริการ

3. ตัวอย่างการยอมรับ (Acceptance Criteria): ลูกค้าทำ Hair Color วันที่ 1 ก.ย., Rule กำหนดเตือน Treatment หลัง 30 วัน (และเปิด Consent) ระบบสร้าง Reminder ส่งวันที่ 1 ต.ค.

4. ประเด็นที่ต้องยืนยันเพิ่มเติม / เงื่อนไขเลือก:
* การส่งข้อความโปรวันเกิด: [ ] วันที่ 1 ของเดือนเกิด [ ] ล่วงหน้า 7 วันก่อนวันเกิด
* ข้อความแจ้งเตือน Service Reminder: [ ] ใช้ Template กลาง [ ] กำหนดข้อความแยกตามบริการ
